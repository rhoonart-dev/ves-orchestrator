# edit_overrides/v3 images[] 합성 구현 (F-408 엔진 파트)

(편집실 v2 Phase 4 · 엔진 세션 E2 · ai-video 레포 — E1 머지 후에 열 것)

## 필독
- E1 세션이 남긴 v3 계약 문서(images[] 스키마: {file, source_time_sec, duration_sec,
  x, y, w, layer})와 '명시적 미지원 에러' 지점. E1 머지가 선행 조건 — 안 돼 있으면 멈추고 보고.

## 컨텍스트
편집실에서 자막처럼 시간 구간을 갖는 이미지(스티커·짤)를 얹는 기능. 역할 분담이 결정돼
있다: **엔진은 로컬 파일만 받는다** — 스토리지 다운로드는 오케스트레이터 aivideo 어댑터가
key→run_dir 파일로 변환해 넘긴다(엔진이 스토리지 자격을 갖지 않는 현행 규율 유지).
좌표는 tts·v3 자막과 같은 원본 절대초 앵커 — 구간 편집과 독립.

## 작업 범위·결정사항
1. images[] 를 받아 ffmpeg overlay 로 합성: file(png/jpg, 알파 지원), 시간 창은 앵커 규칙
   (담은 클립 오프셋 + 상대시각, 슬롭 ±0.5s, 클립 밖 앵커는 tts 고아와 같은 규칙),
   위치 x·y(비율→px), 폭 w(비율→px, 세로는 원본비 유지), layer 순서(자막 아래/위 결정은
   layer 값으로 — 기본은 자막 아래).
2. 파일 검증: 확장자·크기 상한(재량으로 정하되 계약 문서에 기록), 없는 파일은 fail-loud.
3. E1 의 '미지원 에러' 제거, validate 에 images 검증 편입, 계약 문서 갱신.

## 검증
실측 1회: resume 렌더에 이미지 2개(자막과 겹치는 창 1개 포함) — 위치·크기·시간·레이어 확인.

## 멈춤 시점
- overlay 합성으로 render 단계 소요가 눈에 띄게 늘면(기준: 편집 재렌더 재개 6초급이
  30초를 넘기면) 멈추고 수치와 함께 보고 — 편집 루프 속도가 이 기능의 존재 이유보다 우선이다.

시작해라.
