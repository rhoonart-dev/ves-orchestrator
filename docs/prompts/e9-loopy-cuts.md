# E9 — 잔망루피(LOOPY) 구간 잘라내기 : vlp 엔진 발주서

vlp(video-localization-project) 엔진 세션용 작업 프롬프트. 기준: 9c1327d(E6-0 머지,
전 노드 last_seen 동일). 사용자 요청(8/20): "혜미리예채파·잔망루피도 다른 채널들과
완전 동일하게 편집". 혜미리예채파(SHOTCONE)는 ai-video 런이 있어 KR 편집실 전체를
0063 체인(편집 재렌더 → 재번역)으로 열었다. **잔망루피는 유튜브 원본을 통째로
현지화하는 무컷 설계라 ai-video 런 자체가 없다** — KR 편집실을 열 대상이 없으므로,
동등화의 남은 조각은 vlp 에 '구간 잘라내기(cuts)'를 넣는 것이다.

## 계약 (0038 p_edits 확장 — 오케스트레이터가 정본)

p_edits 최상위에 선택 키 `cuts` 를 추가한다:

```json
{ "cuts": [ { "start_sec": 34.0, "end_sec": 41.5 },
            { "start_sec": 80.2, "end_sec": 95.0 } ] }
```

- 좌표는 **완성본(현지화 영상) 시간축** 초 — 편집실 타임라인·ko_ja_pairs 의
  start/end 와 같은 축. 그 구간을 영상에서 들어낸다(앞뒤가 이어 붙는다).
- 검증(즉시 실패): start_sec≥0 · end_sec>start_sec · 서로 겹침 거절 · 최대 20개 ·
  총 삭제 길이가 원본의 80% 이상이면 거절(실수 방지).
- 구 엔진은 모르는 최상위 키를 조용히 무시한다 — E6-0 과 같은 구도라
  **오케스트레이터는 전 노드 배포 확인 후 플래그로 UI 를 연다**(editor_jp_cuts).

## 구현 (C/BC 우선 — 실운영 라우트, B/BJ 는 같은 규칙으로)

- ffmpeg 로 컷 구간 제거(비디오+오디오 함께, 프레임 정확도는 재인코딩 경로 허용).
- **타임라인 재정렬이 본체**: 컷 뒤쪽의 모든 시각(더빙 events start/end ·
  ja_dub.srt/ass · telops · tts cue · ko_ja_pairs)이 삭제 길이만큼 당겨져야 한다.
  컷 창 안에 걸친 항목: 완전히 안이면 그 줄 제외(use:false 와 동일 의미),
  걸치면 경계로 클램프.
- 오버라이드 적용 순서: cuts 는 **use:false·문구·타이밍 병합 뒤, 합성·SRT 기록
  전에** — 사용자 타이밍(end_fixed)도 당김 대상이다(절대값이 아니라 그 장면에
  붙어 있다).
- 다음 카드 ko_ja_pairs: 당겨진 시각으로 동봉(편집실 재진입이 새 시간축을 본다).
  적용된 cuts 를 메타(notes 또는 별도 키)에 기록 — 검수자가 '왜 짧아졌는지' 안다.

## 검증

C 루트 실측 1회: 중간 컷 1개 + 끝 컷 1개 — 총길이 감소 정확, 컷 경계 전후 자막·
더빙 싱크 프레임 안팎, 컷 안 대사 소실(무언·무자막), pairs 시각 갱신 확인.
