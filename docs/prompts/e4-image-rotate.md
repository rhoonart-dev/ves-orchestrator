# images[].rotate + subtitles[].style.rotate — 회전 (F-410 엔진 파트)

> 2026-08-19 범위 추가(세션 시작 후 사용자 전달): **자막 줄 단위 회전**도 같은 세션에서.
> `subtitles[].style.rotate`(선택, 도 단위 숫자, 시계방향 양수, -180~180, 기본 0) —
> ASS 인라인 `\frz`(ASS 는 반시계 양수 — 부호 변환은 엔진 책임, 문서에 명시).
> validate 의 style 허용 키에 rotate 추가 + 타입·범위 검증, 계약 문서 style 표 갱신,
> 실측에 회전 자막 1줄 포함. 이미지 rotate 와 방향·범위 규약 동일 유지.

(편집실 v2 · 엔진 세션 E4 · ai-video 레포 — E2(dc1060f) 머지 후에 열 것)

## 필독
- docs/edit_overrides_v3.md 의 images 절(E2 구현)과 validate 의 images 검증 지점.

## 컨텍스트
편집실에서 스티커·짤을 기울여 얹고 싶다는 운영 요청. 지금 계약(images[] {file,
source_time_sec, duration_sec, x, y, w, layer})에는 회전이 없고, 모르는 키는
즉시 거절이 규약이라 엔진이 먼저 열어야 한다.

## 작업 범위
1. images[] 에 `rotate` 키(선택, 도 단위 숫자, 시계방향 양수, 원점 = 이미지 중심,
   범위 -180~180, 기본 0) — ffmpeg rotate 로 합성(알파 보존: ow/oh 재계산 +
   fillcolor 투명 또는 동급). `w`(너비 비율)는 회전 **전** 원본 기준을 유지한다
   (회전으로 바운딩 박스가 커져도 w 해석이 안 바뀌게 — 문서에 명시).
2. validate: images 허용 키에 rotate 추가, 타입·범위 검증(모르는 키 거절은 유지).
3. 계약 문서 갱신 + 실측 1회: 90°·45° 각 1, 자막과 겹치는 창 1 — 위치·알파 확인.
