# E11 — 자막 전사 백엔드 실측 보고 (2026-08-22)

발주서: `e11-transcribe-backend.md`. 엔진 구현은 머지됐고(전 노드 `e99cf6a`) **실측이
빠져 있었다** — 이 문서가 E11-3 다섯 항목의 실측 결과이자 게이트 판단 근거다.

측정은 파이프라인 작업 등록이 아니라 엔진이 들고 있는 A/B 도구
(`ai-video/scripts/e11_transcribe_ab.py`)를 노드에서 직접 돌려서 했다 — 작업 등록 RPC 는
operator 권한이고, 게이트가 off 라 어차피 파이프라인으로는 elevenlabs 경로를 탈 수 없다.

### 어절 일치율 85.8% 의 분해 — 차이의 대부분은 청취 오류가 아니라 **표기 정책**

상위 30건 차이를 분류하면:

| 부류 | 건수(표본) | 예 | 자막 관점 |
|---|---|---|---|
| 문장부호 추가 (scribe 만) | ~9 | `모르겠는데` → `모르겠는데.` · `일하는가` → `일하는가?` | 중립 (렌더에서 어차피 다듬는다) |
| 맞춤법·띄어쓰기 (scribe 정답) | 3 | `살만하니까`→`살 만하니까` · `운영해온`→`운영해 온` · `그 다음`→`그다음` | scribe 우세 |
| 청취 교정 (scribe 정답) | 2 | `눈간에`→`누구나` · `하지라고`→`하시려고` | scribe 우세 |
| 청취 오류 (whisper 정답으로 보임) | 4 | `제`→`쟤` · `살짝`→`잘` · `짠`→`쓰면` · `들을`→`될` | whisper 우세 |
| **영문 약어·숫자 한글 풀어쓰기** | 5 | `SK텔레콤`→`에스케이텔레콤` · `NC소프트`→`엔씨소프트` · `CTO`→`씨티오` · `IT업계`→`아이티 업계` · `30년`→`삼십년` | **whisper 우세 — 자막 관례 위반** |
| 필러·구어 유지 (scribe) | 7+ | `어` · `이제` 삽입, `있으면`→`있으면은`, `해봤지만`→`해봤지만은` | whisper 우세 (자막은 필러를 뺀다) |

**청취 정확도 자체는 사실상 동률이다** — 서로 2~4건씩 잡아낸다. 벌어진 14.2%p 는
문장부호·필러·표기 관례 차이가 만든 것이고, 그중 자막 품질에 실제로 해로운 쪽은
scribe 다(고유명사를 한글로 풀어써서 화면에 `에스케이텔레콤`, `씨티오`, `삼십년` 이 뜬다).

## 게이트를 켜기 전 막는 것 2건

**B1. cue 규칙이 다르다 (블로커).** 206 → 180 줄, 표본 cue 길이 2.00s→4.58s ·
2.90s→5.02s. 일레븐랩스 쪽 자막 한 줄이 **두 배 가까이 길다**. 발주서 E11-1 의 전제는
"두 백엔드가 같은 좌표계·**같은 cue 규칙**으로 돌아와야 한다" 였는데 좌표계만 맞고
cue 규칙이 안 맞는다. 이 상태로 게이트를 켜면 채널 하나만 백엔드를 바꿔도 자막 줄
길이가 통째로 달라진다 — 디자인 회귀다.

**B2. 고유명사·숫자 표기.** `SK텔레콤`·`CTO`·`30년` 이 한글로 풀려 나온다. 후처리
없이는 자막으로 못 쓴다.

**미측정 1건.** E11-3 항목 4(회귀 0)는 A/B 도구의 사정거리 밖이다 — 이 도구는 전사
단계만 두 번 돌릴 뿐 파이프라인 완성본을 비교하지 않는다. 플래그 없는 실행이 종전과
같은지는 같은 소스로 작업 두 건을 돌려 `--diff JOB_A JOB_B` 로 재야 한다.

## 결론 — `channel_transcribe` 게이트는 **off 유지**

속도(9배)와 요금($0.22/시간)은 쓸 만하고 이벤트 누출·싱크는 깨끗하다. 그러나 B1 이
디자인 회귀를 만들고 B2 가 자막 품질을 떨어뜨린다. 둘 다 엔진 쪽 후처리(cue 재분할 +
고유명사 표기 보존)로 닫아야 켤 수 있다.

## 실측 중 드러난 엔진 결함 2건 (E11 범위 밖, 별건 처리 필요)

- `app/modules/ffmpeg_utils.py:163` — ffmpeg 미검출 메시지가 **윈도우 설치법**을 안내한다.
  전 노드가 macOS 다. (운영 영향 없음 — 워커는 PATH 를 주입한다. 수동 실행 때만 걸린다.)
- `app/modules/tts.py:278` — `EL_VOICE_PRESETS.get(voice, EL_VOICE_PRESETS[DEFAULT_VOICE])`.
  모르는 **라벨**이 조용히 기본 목소리로 떨어진다(E12 가 고치는 `elevenlabs:` 접두사
  경로와 달리 라벨 경로는 여전히 fail-silent). E12 와 같은 규율로 즉시 실패해야 한다.

## 재현 방법

```
ssh <노드> 'export PATH=/opt/homebrew/bin:/usr/local/bin:$PATH;
  set -a; . /opt/ves/secrets/ves.env 2>/dev/null; . /etc/ves/node.env 2>/dev/null; set +a;
  cd /opt/ves/engines/ai-video && .venv/bin/python -m scripts.e11_transcribe_ab \
    --video /opt/ves/cache/sources/<sha> --json-out /tmp/e11_ab.json'
```

`ELEVENLABS_API_KEY` 는 `/opt/ves/secrets/ves.env` 에 있다(ai-video `.env` 아님 —
`ves/config.py:44-48` 이 정한 순서). 비대화형 SSH 는 PATH 에 homebrew 가 없어 ffmpeg 를
못 찾으므로 위 `export` 가 필요하다.
